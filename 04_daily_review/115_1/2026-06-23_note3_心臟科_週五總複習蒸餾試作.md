## 高頻骨架

### 115-1 心臟紅點

- Ischemic heart disease（IHD，缺血性心臟病）檢查最值得優先：exercise ECG vs stress imaging、Agatston score、SPECT reversible defect、TIMI flow、FFR、OCT/IVUS。
- Stable angina（穩定型心絞痛）：運動胸痛＋休息/NTG 改善；若 troponin/CK 上升，就不是單純 stable angina。
- Exercise ECG：for 能運動且 ECG 可判讀；LBBB、LVH、digoxin 會干擾 ST depression。
- SPECT：可逆缺損＝ischemia；固定缺損＝舊 MI/疤；lung uptake/TID 可提示 multivessel/left main 高風險。
- Coronary calcium Agatston score：不用顯影，主要做風險分層；不是典型胸痛的一律最佳診斷。
- 心導管檢查：TIMI flow grade 3＝正常灌流；FFR <0.80 支持功能性狹窄；OCT 解析度高於 IVUS 但較淺。
- 115-1 HTN 訊號：target organ damage 看腦心腎周邊眼；次發性 HTN workup 重 Cr/K/thyroid，uric acid 不是主機轉檢查。
- HTN 是 stroke 強風險，但整體 stroke 仍多為 ischemic，不是多數腦出血。
- MAT（multifocal atrial tachycardia，多源性心房頻脈）：COPD/低氧/重病老人；心跳 >100、>=3 種 P 波；不是 AF，通常不需抗凝。
- Vaughan Williams trap：Class IV antiarrhythmic 是 non-DHP CCB（diltiazem/verapamil），不是 amlodipine。
- IE（infective endocarditis，感染性心內膜炎）手術：acute severe valve destruction with HF、perivalvular abscess/fistula、unstable prosthetic valve；血培 3 天未陰性本身不夠。
- Syncope（暈厥）三大類：neurally mediated、cardiac、orthostatic；「operation-related syncope」不是標準分類。

### 高血壓與大動脈

- Secondary HTN 線索：<30 歲、>60 歲新發、突然惡化、resistant HTN；口訣＝腎內主神藥。
- 腎實質病＝最常見 secondary HTN；內分泌性次發 HTN 最常考 primary aldosteronism（常低 K）。
- Hypertensive urgency：BP >180/120 但無 end-organ damage → 口服藥慢慢降。
- Hypertensive emergency：BP >180/120 + 腦心腎眼/主動脈傷害 → IV nicardipine/labetalol；中風避免 nitroprusside/NTG，可能升 ICP。
- ACEi/ARB：適合 DM/CKD/proteinuria；禁孕婦、雙側腎動脈狹窄、高 K。
- β-blocker 不是單純 HTN 首選；有 CAD/HFrEF/arrhythmia 才加分。HFrEF 實證 β-blocker＝carvedilol、bisoprolol、metoprolol succinate。
- Pregnancy HTN：labetalol、nifedipine、methyldopa；禁 ACEi/ARB。
- AAA repair/EVAR：有症狀、破裂、快速擴大、無症狀男 >=5.5 cm/女 >=5.0 cm。
- Acute aortic syndrome（AAS）：aortic dissection、intramural hematoma、penetrating aortic ulcer。
- AAS 影像：穩定首選 CTA；不穩定/不能搬動用 TEE；CXR mediastinum widening 不能排除。
- AAS 治療：先 IV beta-blocker 把 HR <60，再加 vasodilator 控 SBP <120；不可先單用 vasodilator。
- Stanford A（升主動脈）→ surgery；Stanford B（降主動脈）→ 先內科控壓，破裂/缺血/持續痛/擴大才 TEVAR/surgery。

### 缺血性心臟病與 ACS

- ACS 分類：UA＝troponin 陰性；NSTEMI＝troponin 陽性無 ST elevation；STEMI＝ST elevation。
- 胸痛急診：10 分鐘內 ECG＋serial troponin；早期 troponin 正常不能排除 MI。
- STEMI：典型胸痛＋ST elevation → 先 reperfusion，不等 troponin。
- Primary PCI 首選，FMC-to-device <=90 min；若 PCI 無法 <=120 min 且症狀 <12 hr → fibrinolysis，door-to-needle <=30 min。
- 溶栓失敗、cardiogenic shock、ongoing ischemia、症狀 >12 hr 仍缺血 → PCI/rescue PCI。
- NSTE-ACS 不一定立刻 cath：休克/持續痛/惡性心律＝immediate；GRACE >140、troponin 動態上升、ST/T 動態變化＝early。
- Inferior MI（II/III/aVF）多 RCA；septal MI（V1-V2）多 LAD。
- Inferior MI 加做 right-side ECG V4R；若 V4R ST elevation，避免 nitrate/利尿劑，因右室 MI 怕 preload 掉。
- ACS 急性藥：aspirin + P2Y12 inhibitor + heparin；O2 只給低氧/呼吸窘迫，不是人人給。
- 次級預防：DAPT、high-intensity statin、beta-blocker、ACEi/ARB（前壁 MI/HF/DM/HTN/CKD 特別重要）。
- MI 機械併發症：papillary muscle rupture＝急性 MR；VSR＝新 holosystolic murmur + thrill；free wall rupture＝tamponade/PEA。

### 心律不整與急救

- ACLS 先看穩不穩定。有脈但不穩 tachycardia → synchronized cardioversion；無脈 VF/pulseless VT → defibrillation + CPR。
- Narrow regular tachycardia：PSVT/AVNRT/AVRT → vagal maneuver → adenosine。
- Narrow irregular：AF、atrial flutter with variable block、MAT；先 rate control，再看 rhythm/anticoagulation。
- Wide QRS tachycardia：先當 VT，除非很確定是 SVT with aberrancy；穩定可 amiodarone/procainamide，不穩定同步電復律。
- Torsades de pointes：QT prolongation + polymorphic VT → MgSO4、補 K/Mg、停 QT 延長藥。
- AF：irregularly irregular、無一致 P 波；抗凝用 CHA2DS2-VASc，不用 aspirin 取代。
- Non-valvular AF 優先 DOAC；mechanical valve 或中重度 mitral stenosis 合併 AF → warfarin。
- Adenosine：規則窄 QRS SVT；WPW + AF 禁用。
- Mobitz I：PR 漸長後掉拍；Mobitz II：PR 固定突然漏拍，較危險，常要 pacing。
- 心臟移植後 bradycardia：迷走神經已切斷，atropine 效果差，別延誤 pacing/升壓藥。

### 瓣膜、心內膜、心包膜

- Murmur timing：AS/PS＝systolic ejection；AR/PR＝diastolic；MS/TS＝diastolic rumbling；MR/TR＝holosystolic。
- 右心雜音吸氣變大；左心雜音多吐氣較清楚。
- Valsalva/站立：HOCM murmur 變大、MVP click/雜音提早；蹲下：HOCM 變弱、AS 多變強。
- MS：diastolic rumbling、左房大→AF/肺高壓；最嚴重時 S1 反而小聲/無聲。
- Acute MR：可由 MI 後 papillary muscle rupture，會肺水腫/shock；降 afterload/preload + IABP/手術。
- Chronic severe primary MR：修補優於置換；有症狀或 LVEF <=60% / LVESD >=40 mm 偏手術。
- AS：systolic ejection murmur + angina/syncope/HF；severe AS 避免脫水/過度 vasodilator；有症狀 severe AS 或 LVEF <50% → AVR。
- AR：early diastolic murmur + wide pulse pressure；acute severe AR → 急手術。
- 機械瓣：年輕/可長期抗凝，需終身 warfarin；生物瓣：高齡/出血風險高，不需長期抗凝但會退化。
- IE 診斷：Duke criteria；major＝典型血培、echo vegetation/abscess/new regurgitation。
- IE 影像：低懷疑/低風險先 TTE；高懷疑/高風險或 TTE 陰性仍懷疑 → TEE。
- IE 牙科預防：人工瓣/修補材料、曾 IE、高風險 CHD、心臟移植後瓣膜病；一般 MVP/MS/MR/AS/AR 不常規給。
- Pericarditis：pleuritic chest pain + friction rub + diffuse ST elevation / PR depression；Tx＝NSAID + colchicine。
- Tamponade：obstructive shock；echo 優先；Beck triad＝hypotension + distant heart sound + JVD；Tx＝pericardiocentesis。
- Tamponade 避免 diuretic、beta-blocker、nitrate，因會降 preload/CO。

### 心肌病、心衰、暈厥

- DCM：心室擴大 + 收縮功能下降；MRI LGE 常 mid-wall；MI 則從 subendocardial 開始。
- DCM 不常規抗凝；只有 AF、心室血栓、栓塞史才給。
- HCM：AD sarcomere mutation；站立/Valsalva 使 LVOT obstruction 增加，murmur 變大。
- HCM Tx：避免劇烈運動 + beta-blocker/verapamil；禁 vasodilator、過度利尿、降 preload。
- RCM：心室壁僵硬 + 舒張功能下降；最常見 amyloidosis；找不到原因再 biopsy。
- Left atrial myxoma：成人最常見原發良性心臟腫瘤；姿勢性暈厥、栓塞；Tx＝手術切除。
- HFrEF：EF <=40%，四大柱＝ARNI/ACEi/ARB、實證 beta-blocker、MRA、SGLT2 inhibitor。
- HFpEF：EF >=50% + 充填壓高；老年女、肥胖、HTN/LVH、AF、DM、CKD；Tx＝利尿緩解鬱血 + 控共病 + SGLT2 inhibitor。
- Diuretics：改善鬱血症狀，不是 HFrEF 主要預後藥。
- High-output HF：CO 高但周邊仍不夠；甲亢、嚴重貧血、AV fistula、beriberi、肥胖、肝病；不是 HFpEF。
- BNP <100 通常可排除 HF；肥胖 BNP 偏低，腎衰/高齡 NT-proBNP 偏高；ARNI 會讓 BNP 不降反升，追蹤較看 NT-proBNP。
- ICD：猝死倖存者或 optimal medical therapy 後 LVEF <=35% 且符合 NYHA；CRT：LBBB/傳導延遲 + 低 LVEF。
- Cardiac syncope 紅旗：運動中/坐姿、無前兆、家族猝死；EKG 第一線。
- Orthostatic syncope：站立 3 分鐘內 SBP↓ >=20 或 DBP↓ >=10；做躺/坐/站血壓。

## 易混淆 / 反直覺

- STEMI 不等 troponin；ST elevation + 典型胸痛先開 reperfusion pathway。
- Primary PCI 是 STEMI 首選；fibrinolysis 是 PCI 延遲時的替代，不是同級第一選。
- TIMI risk score 高＝危險；TIMI flow grade 高＝灌流好。
- DAWN/DEFUSE-3 是腦中風 thrombectomy 條件，不是 MI PCI 條件。
- Exercise ECG 不是萬用：不能運動或 ECG 難判讀就改 stress imaging / coronary CT。
- Stable angina 做 cath/PCI 不等於一定降低 MI 或死亡，重點常是症狀控制與高風險解剖。
- RV infarct 不是給 nitrate 越多越好；右室靠 preload，nitrate/diuretic 可讓血壓垮。
- AF 和 MAT 都可 irregularly irregular；MAT 有多種 P 波，通常不用抗凝。
- Aspirin 可用於 CAD/ACS/PCI，但不能替代 AF anticoagulation。
- DOAC 不適用 mechanical valve / 中重度 MS 的 AF；這兩個仍 warfarin。
- Wide QRS tachycardia 先當 VT，考試不要太快假設 SVT with aberrancy。
- Amlodipine 是 DHP CCB，不是 Class IV antiarrhythmic。
- HFrEF rate control 小心 diltiazem/verapamil，因 non-DHP CCB 壓心肌收縮。
- Severe AS、HOCM、tamponade 都怕亂降 preload/afterload，但原因不同：AS 固定出口、HOCM 出口阻塞、tamponade 需要填充壓維持 CO。
- Pulsus paradoxus 想 tamponade；Kussmaul sign 想 RV infarct / constrictive pericarditis / RCM。
- Pericarditis 是 diffuse ST elevation/PR depression；STEMI 是局部導程 ST elevation + reperfusion。
- IE 治療 3 天仍發燒不等於手術；7-10 天菌血症不清、abscess/fistula、急性嚴重瓣膜破壞才更像手術點。
- 一般瓣膜病或 MVP 看牙不常規 IE prophylaxis；只有高風險族群要。
- Hyperkalemia 的 calcium gluconate 只穩心肌，不降 K；降 K 靠 insulin/glucose、beta agonist、dialysis 等。
- HTN emergency 的重點不是數字本身，而是 end-organ damage。
- 高齡 CAD/頸動脈狹窄者 DBP 壓太低會傷 coronary/cerebral perfusion；降壓不是越低越好。
- tPA bleeding reversal 偏 cryoprecipitate ± TXA/aminocaproic acid；不是 vitamin K。
