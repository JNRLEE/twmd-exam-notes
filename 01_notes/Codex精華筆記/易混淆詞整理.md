# 易混淆與相反規則整理

> 這裡放跨科同名、同縮寫、同 marker（腫瘤標記）但意義不同，或看起來有方向性但換疾病就不能套用的考點。主筆記保留原脈絡，這份用來考前快速防混。

## 待補充：鏢靶藥物對應標靶

## 同名但不同東西

| 詞 | 易混點 | 核心分辨 |
|---|---|---|
| Clear cell（透明細胞） | RCC（腎細胞癌）、卵巢、子宮內膜、骨腫瘤都有 | 一定加器官；Endometrial clear cell（子宮內膜透明細胞癌）預後差；Clear cell RCC（透明細胞腎細胞癌）是腎癌 subtype（亞型）；Ovarian clear cell（卵巢透明細胞癌）常和 endometriosis（子宮內膜異位症）相關，不要只背預後好 |
| Marcus Gunn | Marcus Gunn syndrome（下頷瞬目症候群） vs Marcus Gunn pupil（相對傳入瞳孔缺損/RAPD） | syndrome＝jaw-winking ptosis（下巴動帶動眼瞼）；pupil＝afferent defect（傳入路徑缺損） |
| Horner | Pancoast tumor（肺尖腫瘤）、neuroblastoma（神經母細胞瘤）、PICA stroke（後下小腦動脈中風）、ICA aneurysm（內頸動脈瘤）、眼瞼下垂都可見 | 三徵固定：ptosis（眼瞼下垂）+ miosis（縮瞳）+ anhidrosis（無汗）；病因看位置 |
| Charcot | Charcot triad（膽管炎三徵）、Charcot-Marie-Tooth（遺傳周邊神經病）、Charcot-Leyden crystals（嗜酸性球結晶） | triad＝膽管炎；CMT＝遺傳周邊神經病；Leyden＝嗜酸性球/過敏黴菌性鼻竇炎 |
| coffee bean（咖啡豆） | sigmoid volvulus（乙狀結腸扭轉）影像 vs granulosa cell nuclei（顆粒細胞核） | volvulus 是 X-ray 外觀；granulosa 是病理核溝 |
| Type I / Type II | AV block（房室傳導阻滯）、bipolar（雙相情緒障礙）、schizophrenia（思覺失調症）、hypersensitivity（過敏反應）、AIP（自體免疫胰臟炎）都有 | type 沒有跨章意義，每次綁疾病名 |
| AMH | AIS（雄性素不敏感症） vs ovarian reserve（卵巢庫存） | AIS：Sertoli cell（支持細胞）分泌使 Mullerian duct（苗勒氏管）退化；不孕：反映 AFC（竇卵泡數）/卵巢庫存 |
| GnRH agonist（促性腺激素釋放素促效劑） | 性早熟、內膜異位/肌瘤、不孕誘導排卵都出現 | 連續用＝downregulation（受體下降調節）；trigger/脈衝情境效果不同 |
| Mucin / Muco-（黏液） | allergic mucin（過敏黏液）、mucinous ovarian tumor（黏液性卵巢腫瘤）、mucoepidermoid carcinoma（黏液表皮癌）、mucosal neuroma（黏膜神經瘤） | 字根相同但疾病不同：過敏黏液、卵巢病理、唾液腺癌、MEN2B |

## Marker/病理名詞

| 詞 | 易混點 | 核心分辨 |
|---|---|---|
| AFP（甲型胎兒蛋白） | 產前篩檢、HCC（肝細胞癌）、hepatoblastoma（肝母細胞瘤）、yolk sac/testis（卵黃囊瘤/睪丸癌） | 產科：AFP↑ NTD（神經管缺損）/gastroschisis（腹裂）、AFP↓ trisomy（三染色體）；腫瘤：HCC/yolk sac/hepatoblastoma 多看升高 |
| beta-hCG / hCG（人類絨毛膜促性腺激素） | 懷孕、GTD（妊娠滋養細胞疾病）、Down/Edwards、GCT（生殖細胞瘤）、OHSS（卵巢過度刺激症候群）、甲亢 | 先判斷情境：產篩、懷孕追蹤、腫瘤 marker、促排卵藥物 |
| LDH（乳酸脫氫酶） | Light criteria（肋膜積液分類）、Ranson（胰臟炎預後）、溶血、PNH（陣發性夜間血紅素尿）、dysgerminoma/Ewing | 非特異：cell injury（細胞傷害）/tumor burden（腫瘤負荷）/體液分類 |
| CA-125 | 卵巢癌、endometriosis（子宮內膜異位症）、月經、腹膜炎 | 不可單獨診斷 ovarian cancer（卵巢癌） |
| CEA（癌胚抗原） | 消化道 adenocarcinoma（腺癌）、medullary thyroid carcinoma（甲狀腺髓質癌）、肺癌/支氣管炎 | 偏追蹤 marker，不是單一癌症特異診斷 |
| SCC（鱗狀細胞癌） | 肺、子宮頸、頭頸、食道、皮膚、陰莖、膀胱、眼瞼都有 | 同是 squamous（鱗狀），但 RF（危險因子）/位置/副腫瘤看器官 |
| Adenocarcinoma（腺癌） | 肺、胃、胰、攝護腺、食道、子宮內膜、大腸都有 | 組織型，不同器官 RF 不可混用；食道腺癌才是 GERD/Barrett |
| Serous / mucinous / endometrioid（漿液性/黏液性/子宮內膜樣） | 卵巢與子宮內膜都用這些病理名 | 子宮內膜：endometrioid 較好，serous/clear cell 差；卵巢：high-grade serous 是主力惡性 |
| Teratoma（畸胎瘤） | ovarian mature（卵巢成熟型）、ovarian immature（卵巢未成熟型）、sacrococcygeal（薦尾部）、testicular（睪丸） | 年齡/器官決定良惡性；mature cystic ovarian 多良性，immature 是惡性 |
| Seminoma / Dysgerminoma（精原細胞瘤/無性細胞瘤） | 睪丸 seminoma vs 卵巢 dysgerminoma | 類似 counterpart（對應物）；都可 LDH↑，但處置依器官不同 |
| Klatskin tumor / Krukenberg tumor | 都是 K 開頭、都和 GI/婦科腫瘤容易混 | Klatskin＝hilar cholangiocarcinoma（肝門部膽管癌）, 在左右 hepatic duct bifurcation（肝管交會處）, 無痛性黃疸/膽道阻塞；Krukenberg＝卵巢轉移癌, 常來自胃 diffuse type/signet-ring cell carcinoma（印戒細胞癌）, 常雙側卵巢 |
| Kocher / Kerley / Kernig | K 開頭又都不是同系統 | Kocher incision（右肋下膽囊切口）/Kocher maneuver（十二指腸胰頭游離）；Kerley B line＝肺水腫間質線；Kernig sign＝腦膜刺激徵 |
| Courvoisier sign / Charcot triad / Reynolds pentad | 都是膽道阻塞感染相關名詞 | Courvoisier＝無痛性黃疸＋可摸到膽囊, 想 pancreatic/periampullary malignancy；Charcot＝fever+RUQ pain+jaundice（急性膽管炎）；Reynolds＝Charcot＋shock＋AMS |
| Virchow node / Sister Mary Joseph nodule / Krukenberg tumor | 都可指胃腸癌轉移但位置不同 | Virchow＝左鎖骨上淋巴結；Sister Mary Joseph＝肚臍轉移結節；Krukenberg＝卵巢轉移 |
| Pancoast tumor / Horner syndrome | 都和肺尖、眼瞼下垂可一起出現 | Pancoast＝肺尖腫瘤, 肩臂痛/臂神經叢侵犯；Horner＝ptosis+miosis+anhidrosis, 可由 Pancoast、ICA lesion、brainstem 等造成 |
| Wilms tumor / Warthin tumor / Whipple disease / Whipple operation | W 開頭很醜名 | Wilms＝兒童腎母細胞瘤；Warthin＝腮腺良性腫瘤, smoking/淋巴間質；Whipple disease＝Tropheryma whipplei 吸收不良；Whipple operation＝胰十二指腸切除 |
| Meckel diverticulum / Merkel cell carcinoma | Meckel vs Merkel 只差一個字 | Meckel＝小腸憩室, rule of 2, ectopic gastric mucosa 出血；Merkel＝皮膚神經內分泌癌, 老人/免疫低下/紫紅結節, Merkel polyomavirus |
| Castleman disease / Carcinoid syndrome / Carney complex | C 開頭稀有病名 | Castleman＝淋巴增生疾病；Carcinoid syndrome＝flushing, diarrhea, bronchospasm, 右心瓣膜, 不以高血壓為主；Carney complex＝myxoma（黏液瘤）+皮膚色素+內分泌腫瘤 |

## 人名病同類比較

| 同一類 | 人名病 | 它在幹嘛 | 核心分辨 |
|---|---|---|---|
| 低血鉀代謝性鹼中毒 | Bartter syndrome（巴特氏症候群） | 腎小管 salt wasting，像長期用 loop diuretic | TAL（粗上升支）Na-K-2Cl 問題；尿鈣高/正常, 年紀較小, RAAS↑但血壓正常 |
| 低血鉀代謝性鹼中毒 | Gitelman syndrome（吉特曼症候群） | 腎小管 salt wasting，像長期用 thiazide | DCT（遠曲小管）Na-Cl 問題；低尿鈣 + 低血鎂, 較晚發 |
| 先天膽紅素代謝 | Gilbert syndrome（吉爾伯特症候群） | 輕微 UGT 活性下降 | unconjugated bilirubin 輕微↑, 壓力/禁食後黃疸, 良性 |
| 先天膽紅素代謝 | Crigler-Najjar syndrome（克里格勒-納賈爾症候群） | UGT 嚴重缺陷 | unconjugated bilirubin 大幅↑；type I 完全缺乏會 kernicterus（核黃疸） |
| 先天膽紅素排泄 | Dubin-Johnson syndrome（杜賓-強生症候群） | conjugated bilirubin 排到膽汁障礙 | direct bilirubin↑, 肝切片黑色 pigment |
| 先天膽紅素排泄 | Rotor syndrome（羅特症候群） | 肝細胞攝取/儲存 conjugated bilirubin 障礙 | direct bilirubin↑, 沒有黑肝 pigment |
| 食道破裂/撕裂 | Mallory-Weiss tear（馬洛里-魏斯裂傷） | 劇烈嘔吐後黏膜裂傷 | 不完全破裂, hematemesis（吐血）, 多保守/內視鏡止血 |
| 食道破裂/撕裂 | Boerhaave syndrome（布爾哈夫症候群） | 劇烈嘔吐後全層食道破裂 | 胸痛/皮下氣腫/縱膈炎, 外科急症 |
| 胃腸瘜肉/癌症遺傳 | Peutz-Jeghers syndrome（波伊茨-耶格症候群） | hamartomatous polyps + mucocutaneous pigmentation | STK11, 嘴唇口腔黑斑, 胰/腸/婦科癌風險↑ |
| 胃腸瘜肉/癌症遺傳 | Lynch syndrome（林奇症候群） | DNA mismatch repair 缺陷 | 右側大腸癌、子宮內膜癌；不是滿腸瘜肉 |
| 胃腸瘜肉/癌症遺傳 | FAP / Gardner syndrome（家族性腺瘤性瘜肉症/加德納） | APC 突變, 腸道大量 adenomatous polyps | 幾乎必癌；Gardner 加 osteoma/soft tissue tumor |
| 肝靜脈/小靜脈阻塞 | Budd-Chiari syndrome（巴德-基亞里症候群） | hepatic vein outflow obstruction | 肝大、腹痛、腹水；常和血栓/MPN 有關 |
| 肝靜脈/小靜脈阻塞 | Sinusoidal obstruction syndrome（veno-occlusive disease） | 小肝靜脈/肝竇阻塞 | 化療/骨髓移植後, 痛性肝大、黃疸、體重增加 |
| 甲狀腺炎 | Graves disease（格雷夫氏病） | TSH receptor stimulating Ab | 甲亢 + diffuse goiter + orbitopathy |
| 甲狀腺炎 | Hashimoto thyroiditis（橋本氏甲狀腺炎） | anti-TPO/anti-thyroglobulin 破壞甲狀腺 | 甲低最常見, 可先短暫 hyper |
| 兒童腎病症候群 | Minimal change disease（微小變化病） | 足突融合, 光學顯微鏡正常 | 小孩 nephrotic 最常見, steroid 反應佳 |
| 兒童腎炎症候群 | Post-strep GN（鏈球菌後腎絲球腎炎） | immune complex GN | nephritic, C3↓, cola urine, 通常支持治療 |
| 神經退化/運動神經 | Parkinson disease（巴金森病） | basal ganglia dopamine↓ | resting tremor, rigidity, bradykinesia |
| 神經退化/運動神經 | Huntington disease（杭丁頓舞蹈症） | CAG repeat, caudate atrophy | chorea, psychiatric, dementia, AD |
| 神經退化/運動神經 | ALS（Lou Gehrig disease） | 上下運動神經元退化 | 感覺通常保留, 眼球/膀胱多保留 |

## High / Low / Grade 不可直接套

| 主題 | 容易套錯 | 正確記法 |
|---|---|---|
| Ovarian epithelial tumor（卵巢上皮腫瘤） | 看到 `low-grade` 就以為預後好 | `High-grade serous`（高度惡性漿液性）是主力惡性、預後差；`Low-grade serous`（低度惡性漿液性）是另一個惡性 subtype，較慢但仍不是「預後好」那類 |
| Endometrial cancer（子宮內膜癌） | 把卵巢 serous 的 low/high 套進子宮內膜癌 | 子宮內膜癌：`Endometrioid grade 1-2`（子宮內膜樣、低分級）較好；`Serous / clear cell / grade 3`（漿液性/透明細胞/高分級）預後差 |
| Endometrial stromal sarcoma（子宮內膜間質肉瘤） | 把 uterine sarcoma（子宮肉瘤）都背成一樣差 | `High-grade/undifferentiated ESS`（高分級/未分化）差；`Low-grade ESS` 相對好、病程較慢 |
| Chondrosarcoma（軟骨肉瘤） | 看到 sarcoma（肉瘤）就只背一種處置 | `High grade` 要更積極 wide excision（廣泛切除）；grade 決定惡性度與處置強度 |
| Prostate Gleason（攝護腺 Gleason 分數） | 以為 grade 越小一定只是良性 | Gleason 是癌症內分級；`>7` 高風險，`7` 中風險，不是良惡性分類 |

## Type I / Type II 不可跨章套

| 主題 | Type I | Type II | 易混提醒 |
|---|---|---|---|
| Schizophrenia（思覺失調症）舊分類 | positive symptoms（正向症狀），預後較好 | negative symptoms（負向症狀），預後較差 | 這裡 I/II 有預後方向 |
| Bipolar disorder（雙相情緒障礙） | mania（躁症） | hypomania（輕躁） + MDD（重鬱） | 不是「I 輕 II 重」；Bipolar I 才有 mania |
| AV block 2nd degree（二度房室傳導阻滯） | Wenckebach，漸行漸遠 | Mobitz II，突然漏拍 | 心臟這裡 Type II 比 Type I 危險，常需 pacer（節律器） |
| Hypersensitivity（過敏反應） | IgE immediate（立即型） | IgG/IgM cytotoxic（細胞毒型） | 只是免疫機轉編號，不代表嚴重度 |
| Autoimmune pancreatitis（自體免疫胰臟炎） | IgG4-related（IgG4 相關），老男，多器官，易復發 | 非 IgG4，較年輕，常合併 IBD/UC，較少復發 | type 編號是病理/流病，不是嚴重度排序 |
| ADPKD（自體顯性多囊腎） | PKD1，常見 | PKD2，較少 | type 是基因，不是一般疾病嚴重度規則 |

## 常見不等於最差

| 主題 | 最常見 | 最差/較危險 | 易混提醒 |
|---|---|---|---|
| Thyroid cancer（甲狀腺癌） | Papillary（乳突癌），預後好 | Anaplastic（未分化癌）最差；medullary/follicular（髓質癌/濾泡癌）較差 | 甲狀腺最常見反而常考預後好 |
| Eyelid tumor（眼瞼腫瘤） | Basal cell carcinoma（基底細胞癌），低轉移 | Sebaceous carcinoma（皮脂腺癌）最惡性 | 眼瞼 BCC 常見但不是最兇 |
| Skin cancer（皮膚癌） | Basal cell carcinoma 最常見 | Melanoma（黑色素瘤）死亡最多 | 皮膚癌「常見」和「致死」分開背 |
| Salivary gland tumor（唾液腺腫瘤） | Pleomorphic adenoma（多形性腺瘤）最常見良性 | Mucoepidermoid（黏液表皮癌）1st malignant；adenoid cystic（腺樣囊性癌）易神經侵犯/遠轉 | 唾液腺先分良性/惡性再背排名 |
| Lung cancer（肺癌） | Adenocarcinoma（腺癌）常見 | SCLC（小細胞肺癌）預後差但化放療敏感 | 快速轉移和治療敏感可以同時成立 |
| Ovarian cancer（卵巢癌） | Epithelial tumor（上皮腫瘤）常見且常晚期 | Germ cell tumor（生殖細胞腫瘤）年輕、惡性者常化療敏感 | 卵巢不同來源腫瘤的年齡/治療反應差很多 |

## 惡性但治療反應好

| 主題 | 容易誤會 | 正確記法 |
|---|---|---|
| SCLC（小細胞肺癌） | 預後差就以為治療反應差 | 轉移快/預後差，但 chemo/radiation sensitive（化放療敏感） |
| Choriocarcinoma / GTD（絨毛膜癌/妊娠滋養細胞疾病） | 會轉移就以為很難治 | beta-hCG 追蹤，化療反應佳 |
| Ovarian malignant germ cell tumor（卵巢惡性生殖細胞腫瘤） | 惡性就以為不保生育 | 多年輕、單側；fertility-sparing surgery（保留生育手術） + BEP，化療敏感 |
| Dysgerminoma / seminoma（無性細胞瘤/精原細胞瘤） | germ cell tumor 都同一套 | counterpart 概念相似，但處置依卵巢/睪丸不同 |
| Ewing sarcoma vs Osteosarcoma（尤文氏肉瘤 vs 骨肉瘤） | 兒童骨惡性腫瘤都同樣放療反應 | Ewing 放療/化療較敏感；Osteosarcoma 放療效果差，手術+化療 |

## Marker 方向相反

| Marker | 情境 A | 情境 B | 易混提醒 |
|---|---|---|---|
| AFP（甲型胎兒蛋白） | 產前 AFP↑：NTD/gastroschisis | 產前 AFP↓：trisomy；腫瘤 AFP↑：HCC/yolk sac/hepatoblastoma | 產篩高低都有意義；腫瘤多看升高 |
| beta-hCG | Down syndrome（唐氏症） ↑ | Edwards syndrome（愛德華氏症） ↓；GTD/GCT/懷孕追蹤多看 ↑ | 先判斷是產篩還是腫瘤/懷孕追蹤 |
| CA-125 | 卵巢癌可升高 | Endometriosis、月經、腹膜炎也可升高 | 不是單獨診斷癌症的 marker |
| LDH | Light criteria 用來分 exudate（滲出液） | Dysgerminoma/Ewing/溶血/Ranson 也會用 | LDH 是非特異 cell injury / tumor burden marker |

## 用藥唯一例外/多選比較

> 國考常考「一群藥裡只有一個可用/不可用/代謝不同/毒性不同」。這裡背例外，不背全藥典。

### 孕婦可用/禁用

| 題型 | 唯一或常考例外 | 記法 |
|---|---|---|
| Pregnancy DVT/PE（孕期深層靜脈栓塞/肺栓塞） | LMWH/UFH 可用；warfarin 禁用 | Heparin 不過胎盤；warfarin 過胎盤→畸形/胎兒出血 |
| Pregnancy HTN（孕期高血壓） | Labetalol、nifedipine、methyldopa 可用；ACEi/ARB 禁用 | ACEi/ARB 傷胎兒腎臟、羊水過少 |
| Hyperthyroidism in pregnancy（孕期甲亢） | 1st trimester 首選 PTU；之後可換 methimazole | PTU 肝毒性；MMI 早孕畸胎風險 |
| SLE pregnancy（SLE 孕期） | Prednisolone、azathioprine、hydroxychloroquine 可用；MMF/cyclophosphamide/MTX 禁用 | Prednisolone 胎盤可分解；MMF/CTX/MTX 會傷胎兒 |
| UTI/antibiotics in pregnancy（孕期抗生素） | PCN、cephalosporin、erythromycin、clindamycin 較安全 | Tetracycline 牙骨；fluoroquinolone 軟骨/肌腱；aminoglycoside 耳腎毒 |
| Antiepileptic pregnancy（孕期抗癲癇） | Valproate 最要避；lamotrigine/levetiracetam 相對常用 | Valproate＝NTD（神經管缺損）+ cognitive risk |
| Gestational diabetes（妊娠糖尿病） | Insulin 最標準 | 口服降糖藥考題常不如 insulin 穩 |

### 腎代謝/肝代謝/腎功能不佳

| 題型 | 唯一或常考例外 | 記法 |
|---|---|---|
| PCN 類 | Oxacillin/nafcillin 偏肝代謝 | PCN 類多腎排；抗葡萄球菌 PCN 是常考例外 |
| Cephalosporin 類 | Ceftriaxone 偏膽汁/肝排，不太需腎調整 | 也可造成 biliary sludge（膽泥） |
| 腎功能不佳抗生素 | Oxacillin、ceftriaxone、metronidazole 較不用調腎 | 常被拿來和 aminoglycoside/vancomycin 對比 |
| Aminoglycoside/vancomycin | 腎毒性、需腎功能調整 | aminoglycoside 還有 ototoxicity（耳毒性） |
| DOAC（直接口服抗凝） | Dabigatran 最依賴腎排 | 腎差時最需要小心 dabigatran |
| Metformin | eGFR <30 禁用/避免 | 乳酸中毒風險 |
| Nitrofurantoin | 只治 lower UTI，不治 pyelonephritis | 腎功能差尿中濃度不足；不是上泌尿道藥 |
| Moxifloxacin | 不適合 UTI | 呼吸道 quinolone，尿中濃度不佳 |
| Statin CYP3A | Lovastatin/simvastatin/atorvastatin 受 CYP3A 影響；pravastatin 最不像 | 葡萄柚汁題常選 pravastatin |

### 殺菌性/抑菌性

| 題型 | 殺菌性 bactericidal | 抑菌性 bacteriostatic | 例外提醒 |
|---|---|---|---|
| 抗生素總整理 | Beta-lactam、vancomycin、aminoglycoside、fluoroquinolone、metronidazole、daptomycin | Macrolide、tetracycline、clindamycin、linezolid、chloramphenicol、sulfonamide | TMP-SMX 合用可視為殺菌；aminoglycoside 是少數殺菌性 protein synthesis inhibitor |
| Endocarditis/meningitis/neutropenia（心內膜炎/腦膜炎/嗜中性球低下） | 常偏好殺菌性 | 單純抑菌常不夠 | 題目問嚴重感染時先想 bactericidal |

### 抗生素唯一特色

| 藥物/類別 | 唯一考點 | 記法 |
|---|---|---|
| Ceftaroline | Cephalosporin 中可打 MRSA | 5th gen = MRSA |
| Ceftazidime / cefepime | 抗 Pseudomonas（綠膿桿菌） | ceftazidime 3rd、cefepime 4th |
| Cefoxitin | 橫膈下/厭氧/婦科 GI 常用 | 2nd gen 但偏 anaerobe |
| Ceftriaxone | Gonorrhea、meningitis；肝膽排 | Rocephin＝不用一直腎調 |
| Aztreonam | 只打 Gram-negative aerobic rods | PCN allergy 可考；不打 G+ / anaerobe |
| Daptomycin | 不能治 pneumonia | 被 surfactant 去活化 |
| Clindamycin | 厭氧 + toxin suppression；C. difficile 風險高 | 壞死性筋膜炎可合併用來壓 toxin |
| Metronidazole | Anaerobe below diaphragm、BV、trichomonas、C. difficile 輕症舊考點 | 酒精 disulfiram-like reaction |
| Aminoglycoside | 不打 anaerobe | 進菌需要氧氣；耳毒性/腎毒性/神經肌肉阻斷 |
| Tetracycline/doxycycline | Atypical、rickettsia、Lyme、chlamydia | 孕婦小孩禁用；牛奶/制酸劑降低吸收 |
| Fluoroquinolone | DNA gyrase；UTI/prostatitis 常用 | 孕婦小孩避免；肌腱斷裂/QT |

### 其他常見「唯一性」比較

| 題型 | 唯一或常考例外 | 記法 |
|---|---|---|
| C. difficile 治療 | 停原抗生素最重要；重症偏 oral vancomycin/fidaxomicin | Metronidazole 是舊式輕症考點 |
| PCP pneumonia in AIDS | TMP-SMX ± steroid | CD4 <200；PaO2 低加 steroid |
| Toxoplasma in AIDS | Sulfadiazine + pyrimethamine + leucovorin | ring lesion；leucovorin 防骨髓毒 |
| Cryptococcus meningitis | Amphotericin B + flucytosine → fluconazole | India ink/cryptococcal antigen |
| Pheochromocytoma 術前 | 先 alpha-blocker，再 beta-blocker | 先 beta 會 unopposed alpha → 高血壓危象 |
| Gout acute vs chronic | 急性 NSAID/colchicine/steroid；慢性 allopurinol/febuxostat | 急性期不要新開降尿酸作為止痛主軸 |
| Migraine acute vs prevention | 急性 triptan/NSAID；預防 beta-blocker/topiramate/TCA | Triptan 禁用 CAD/血管收縮風險 |

## 一句話總結

- `grade` 通常越高越差，但 `low-grade` 不等於「良性」。
- `type I/II` 沒有跨科通用方向，一律綁疾病名。
- `最常見`、`預後最差`、`治療最敏感` 是三個不同欄位，不要互相代換。
- 用藥題先問自己：孕婦、腎功能、肝代謝、殺菌/抑菌、唯一毒性、解毒劑，通常答案藏在例外。

## 目前建議修主筆記

- `Ovarian clear cell`：不要簡化成「預後好」。較適合記「endometriosis 相關、常較早期，但化療反應較差」。
- `Marcus Gunn`：眼科已寫 syndrome != pupil，可保留交叉提醒。
