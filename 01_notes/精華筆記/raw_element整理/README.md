# raw_element 整理工作區

目的：把 `../raw_element.md` 從 PDF 複製造成的題群/答案群，整理成可審核、可追溯的 Q/A。

## 檔案

- `00_segment_index.md`：原始行號與 segment 對照。
- `segments_raw/`：主 agent 依主題切出的原始段落，不改內容。
- `agent_outputs/`：各 worker 產出的互斥段落整理稿。
- `raw_element_QA_整理版.md`：最終整合版。
- `raw_element_校對報告.md`：錯誤、疑義、缺答案、需回查來源的清單。

## Worker 輸出規格

每個題目都要保留可追溯資訊：

| 欄位 | 規格 |
|---|---|
| ID | `Sxx-Qyy`，xx 為 segment 編號，yy 為該 segment 內題序 |
| 題目 | 盡量保留原題意，修掉 PDF 斷行 |
| 整理答案 | 以國考可背短句呈現 |
| 狀態 | `OK` / `修正` / `疑義` / `缺答案` |
| 原始行號 | 題幹與答案可分開寫，例如 `Q: 153-171; A: 175-213` |
| 校對註記 | 若修正或疑義，寫最短理由 |

## 校對原則

- 先做題目-答案配對，再做醫學正誤校對。
- 不把單題冷門補成百科；只修正會導致答錯的內容。
- 若原文答案明顯錯，保留「原文答法」於註記，整理答案寫修正版。
- 若答案缺漏、來源跨到「下頁」但 raw 沒複製到，標 `缺答案`，不可自行假裝完整。
- 英文縮寫第一次出現時補中文或 full name；既有分類標籤如 `Tx`、`Dx` 可不展開。
