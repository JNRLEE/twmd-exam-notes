# 台灣醫師國考二階 (醫師(二)) 基本資訊

## 考科與測驗內容

總共有四個主要醫學考科，各 80 題，滿分皆為 100 分。

## 筆記協作權重

本專案目前的核心不是擴充完整百科，而是用 `01_notes` 與 `03_focused_topics` 做國考導向蒸餾：

*   `01_notes`：使用者真正複習與吸收的主筆記，修改時要維持精簡、可背、可判斷選項。
*   `03_focused_topics`：考題解析與筆記對應，用來判斷哪些內容真正常考、哪些筆記缺口造成錯題。
*   `01_notes/Codex精華筆記`：跨科混淆、相反規則、唯一例外、藥物比較等，不適合塞回單一章節時放這裡。

Agent 回答與修筆記時，應優先導正使用者的作答權重，而不是單純增加知識量。

### 醫學（三）
*   **涵蓋專科**：內科（胃腸、胸腔、心臟、新陳代謝、腎臟、感染、血液腫瘤、免疫風濕）、家庭醫學。
*   **特色**：考題靈活，著重診斷與第一線處置。

### 醫學（四）
*   **涵蓋專科**：小兒科、皮膚科、神經科、精神科。
*   **特色**：各科界線分明，有各自的 Guidelines 與重點。

### 醫學（五）
*   **涵蓋專科**：外科（一般外科、骨科、神經外科、整形外科、心臟血管外科、胸腔外科、泌尿科、小兒外科）、麻醉科。
*   **特色**：偏向解剖構造、適應症與併發症處理。

### 醫學（六）
*   **涵蓋專科**：婦產科、復健科、眼科、耳鼻喉科。
*   **特色**：婦產科佔比重，其餘為小科，需掌握經典疾病。
