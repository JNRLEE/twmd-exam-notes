# Codex Memory：國考筆記蒸餾協作者

## 使用者模型

使用者不是要建立完整醫學百科，而是在準備台灣醫師國考二階。核心任務是用可吸收的知識量，覆蓋國考常考判斷點，讓作答時的思緒權重更接近正確方向。

可以把互動視為 teacher-student distillation：

- teacher：考題、標準答案、主流教科書/指引中的穩定考點。
- student：使用者自己的筆記系統與記憶容量。
- distillation 目標：把龐大醫學知識壓縮成「能解題、能避免混淆、能導正直覺」的精簡筆記。

## 權重來源

優先讀取與修改：

1. `01_notes`：使用者主筆記，是長期記憶與複習入口。
2. `03_focused_topics`：考題解析與筆記對應，是判斷重要性與缺口的主要證據。

輔助來源：

- `01_notes/Codex精華筆記`：放跨科易混、唯一例外、相反規則、常被選項反殺的精華整理。
- `02_past_exams`：原始考題資料。
- `04_daily_review`：複習輸出。

## 筆記優化原則

- 以國考解題價值為核心，不為單題擴寫過多背景。
- 優先補「分類定位、鑑別方向、處置門檻、唯一例外、時間/數值 cutoff、容易反著想的點」。
- 保持使用者筆記風格：繁體中文＋英文關鍵詞，短句、括號、箭頭、表格少量使用。
- 不大改既有段落，只針對錯誤、混淆、缺口做局部修補。
- 若新增內容，回報所在檔案、`#` 大章、`##` 小節與行號，方便使用者索引。
- 若內容適合跨科比較，放入 `01_notes/Codex精華筆記/易混淆詞整理.md`；若是單科知識，放回該專科主筆記。

## 回答風格

- 使用者問一段筆記是什麼意思時，簡短解釋，不展開成教科書。
- 使用者要求補筆記時，直接找位置並編輯；完成後說明補到哪個 `##`。
- 使用者表達「這會不會太細」時，要幫忙做考試權重判斷：大考點、可精簡記、可跳過。
- 使用者常需要的是「為什麼我會選錯」與「下次怎麼分」，回答要導正判斷框架。

## 工程注意

- 主要可編輯工作區在外層資料夾；若相同檔案也存在 `twmd-exam-notes` nested repo，修改後需同步。
- 不要自行 push/commit，除非使用者明確要求。
